# ITEC80D Lab Activities

A repository for ITEC 80D: Human-Computer Interaction graphical user interface lab activities.

## Repository Structure

| Folder | Activity | Description |
|---|---|---|
| [`#1: BMI Calculator GUI`](./%231%3A%20BMI%20Calculator%20GUI) | Laboratory Exercise No. 1 | A Tkinter GUI application that takes a user's height and weight, calculates their Body Mass Index (BMI), and categorizes the result (underweight, normal, overweight, obese). |
| [`#2: Visual Pattern Memory Game GUI`](./%232%3A%20Visual%20Pattern%20Memory%20Game%20GUI) | Laboratory Exercise No. 2 | An interactive cognitive game built with Tkinter that briefly displays a highlighted pattern on a grid, which the user must reproduce from memory. Difficulty increases across 5 rounds (larger grids, more highlighted cells). Collects per-round interaction data (accuracy, completion time, errors), displays it live in a Listbox, and exports it to CSV for HCI analysis (mean, median, standard deviation, error rate). See the folder's own README for setup instructions and full HCI principle breakdown. |

## Tech Stack

- Python 3.x
- Tkinter (GUI framework)
- Google Sheets / Excel / CSV for raw interaction data analysis
