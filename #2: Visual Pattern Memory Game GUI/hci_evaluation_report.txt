1. INTRODUCTION
--------------------------------------------------------------------------------
Human-Computer Interaction (HCI) plays a pivotal role in designing graphical
interfaces that accommodate human cognitive limitations. Visual memory and
spatial recognition are heavily influenced by interface factors such as visual
hierarchy, feedback responsiveness, display time, and cognitive workload. 

This study evaluates the usability, performance efficiency, and user experience
of the Visual Pattern Memory Game GUI. The application tests short-term spatial
memory by presenting a grid of temporarily illuminated cells that participants
must recall and select. The key HCI problem investigated is how scaling grid size
and pattern complexity impacts cognitive load, completion timing, and user accuracy,
and whether prompt UI feedback mitigates recall errors.

--------------------------------------------------------------------------------
2. OBJECTIVES
--------------------------------------------------------------------------------
- To measure user performance (completion time, error rates, and accuracy) across
  scaling levels of spatial complexity.
- To analyze how visual feedback and UI consistency affect user error prevention
  and task confidence.
- To identify usability bottlenecks in the current Tkinter-based GUI implementation.
- To formulate interface improvements based on empirical empirical interaction data.

--------------------------------------------------------------------------------
3. GAME DESCRIPTION
--------------------------------------------------------------------------------
- User Task: The user clicks "Start Game", observes a grid where a specific pattern
  of tiles illuminates for a fixed duration (2000 ms to 3200 ms), and then replicates
  the pattern by clicking the corresponding tiles after they turn dark.
- Interface: Built using Python 3 and Tkinter. Includes a dark-themed card container,
  a dynamic grid display area, active timer labels, control buttons (Start/Submit/Reset),
  an embedded Listbox logging historical trial results, and an interactive instructions popup.
- Progression & Difficulty:
  * Round 1: 3x3 Grid, 3 Active Cells, 2000 ms Display Time
  * Round 2: 3x3 Grid, 4 Active Cells, 2200 ms Display Time
  * Round 3: 4x4 Grid, 5 Active Cells, 2500 ms Display Time
  * Round 4: 4x4 Grid, 6 Active Cells, 2800 ms Display Time
  * Round 5: 5x5 Grid, 7 Active Cells, 3200 ms Display Time
- Total Rounds: 5 progressive rounds per test session.

--------------------------------------------------------------------------------
4. PARTICIPANTS

- Demographics: Age ranges spanned 18–20 years (28.6%) and 21–23 years (71.4%).
- Experience Levels: 2 Beginners, 3 Intermediate, and 2 Advanced users.

5. RAW DATA & DATA CLEANING
--------------------------------------------------------------------------------
Raw logs collected from user testing were inspected prior to analysis:
- Deduplication: Duplicate logs resulting from identical back-to-back testing sessions
  (e.g., duplicate entries for WINXKIEE and P11) were purged to avoid skewing metrics.
- Code Normalization: Participant code "PO1" was standardized to "P01" for consistency.
- Exclusions: Outlier execution sessions where users restarted mid-round were excluded.
- Total Processed Records: 35 clean round records (7 participants × 5 rounds).

7. RESULTS & HCI ANALYSIS
--------------------------------------------------------------------------------
- Cognitive Workload & Pattern Complexity: Completion times generally increased as pattern
  complexity expanded from 3 cells (Round 1) up to 7 cells (Round 5). An initial anomaly in
  Round 1 completion time (4.13s mean) was caused by P03 taking 8.98s to familiarize with the UI.
  Excluding initial orientation time, completion times scaled linearly with complexity.
- Visibility & Feedback: Immediate color-coding on submission (Green = Correct, Red = Wrong,
  Yellow = Missed) gave clear feedback, achieving high user confidence.
- Error Prevention & Affordances: Disabling tile clicking during pattern display successfully
  prevented premature input errors across all test sessions.
- Consistency: Uniform dark theme colors and structural placement reduced visual distraction.

--------------------------------------------------------------------------------
8. OBSERVED USABILITY PROBLEMS & PROPOSED IMPROVEMENTS
--------------------------------------------------------------------------------
1. Problem: First-Time Orientation Delay
   - Evidence: Participant P03 spent 8.98 seconds on Round 1 figuring out controls.
   - HCI Principle: Affordance & Help Guidance.
   - Proposed Improvement: Add an automated modal onboard tutorial on first launch.

2. Problem: Lack of In-Game Undo/Deselect Action Clarity
   - Evidence: Participant P02 accidentally selected a cell in Round 4 and submitted instead
     of deselecting, incurring a 85.71% accuracy score.
   - HCI Principle: User Control & Error Recovery.
   - Proposed Improvement: Implement clear visual toggles and a "Clear Selection" button.

3. Problem: Listbox Data Density
   - Evidence: Users found reading raw string data from the recorded Listbox component difficult.
   - HCI Principle: Visual Hierarchy & Feedback.
   - Proposed Improvement: Format Listbox columns using tabular alignment or a Treeview widget.

--------------------------------------------------------------------------------
9. CONCLUSION
--------------------------------------------------------------------------------
The Visual Pattern Memory Game successfully demonstrates key HCI concepts. Empirical data
confirms that increasing visual pattern complexity increases cognitive completion time.
By enforcing error prevention mechanisms (locking inputs during display) and providing instant
visual feedback, overall user accuracy remained above 97% across all rounds.
