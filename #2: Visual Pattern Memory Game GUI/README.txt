       python main.py

------------------------------------------------------------------------
BRIEF DESCRIPTION
------------------------------------------------------------------------
The Visual Pattern Memory Game is an interactive cognitive assessment application 
designed to test visual memory span, visual pattern recall, and cognitive speed. 
Users are presented with active cells highlighted on a grid (3x3 up to 5x5) for a 
brief display duration. After the pattern disappears, users must select the 
recalled cells on an interactive grid interface.

------------------------------------------------------------------------
KEY HCI ENHANCEMENTS & FEATURES
------------------------------------------------------------------------
1. Interactive Feedback Area: Direct visual status updates ("CORRECT!", "WRONG CELL!")
2. Real-Time Listbox Display: Live presentation of completed trial statistics
3. Error Prevention Controls: Input locking during pattern display phase
4. Graphical Performance Export: Export functionality to CSV / Excel-compatible formats
5. Reset & Control Mechanisms: Seamless restart without losing recorded session metrics
